# Validate connected editable office artifacts

Read the exact task revision and select the checks that address its acceptance criteria. This skill does not expand a task to the entire roadmap or authorize future implementation. These are validation instructions, not claims of an existing product.

1. Use one source sheet, one linked memo and one linked slide. Change an input and inspect the dependent formula, text and rendered view; retain typed editable sources.

2. Test stale links, cycles, unsupported formulas and formatting loss. Report each explicitly rather than replacing the source with a flattened image that appears correct.

3. For proposed changes, accept and reject individual edits; verify unaffected cells, paragraphs and slides remain unchanged. Exercise undo after a concurrent edit by a second actor.

4. Export and reopen the native package in a fresh workspace. For external formats, enumerate the supported subset and prove both a supported round trip and a diagnosed unsupported feature.

5. Exercise reading, selecting, editing and reviewing using each claimed input/accessibility mode. A screenshot is layout evidence only; retain interaction and data-correctness evidence.

For every selected check, record fixture/setup, actions, expected outcome, observed outcome and reproducible evidence. State which checks were not applicable and why; do not count unrun checks as passing.
